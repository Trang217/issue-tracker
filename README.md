# 🎫 Mini Issue Tracker

A simple issue tracker built with **React** and **TypeScript** to create, manage, and track tickets.

## ✨ Features

- ➕ Create new tickets
- 🔍 Search by title or creator
- 🎯 Filter by status and priority
- 📄 View ticket details
- 🔄 Update ticket status
- 💾 Persist data with `localStorage`

## 🛠️ Tech Stack

- ⚛️ React
- 🔷 TypeScript
- ⚡ Vite

## 🚀 Running the Project

```bash
npm install
npm run dev
```

## 💡 Notes

This project started as a frontend coding challenge and has since become a small personal project. I focused on keeping the code clean, reusable, and easy to maintain by separating business logic into custom hooks and utility functions.

Future improvements include:

- 🧪 Adding more tests
- 🆔 Using UUIDs for ticket IDs
- ☁️ Connecting to a backend API
